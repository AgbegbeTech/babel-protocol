# Privacy Boundaries

Private:

- room messages
- room membership
- unapproved translations
- repair discussions
- facilitator inputs
- drafts
- private attachments
- Power Context
- device private keys
- authentication secrets

Publishable only with exact consent:

- Understanding Artifacts
- approved cultural context
- approved translations
- agreement
- unresolved disagreement
- attribution
- evidence
- collaboration projects

Never public:

- private signing keys
- raw secrets
- Cloudflare credentials
- private queue payloads
- internal authorization data
- private object encryption keys
- unapproved transcripts
