# Consent Receipt

Consent is revision-specific.

```text
ConsentReceipt
├── receipt ID
├── artifact ID
├── exact revision hash
├── approving participant
├── approving device
├── approved publication scope
├── attribution preference
├── approved translations
├── AI-processing permissions
├── timestamp
├── optional review date
├── consent statement version
└── signature
```

If the artifact changes, previous approval does not count for the new revision. AI and server operators cannot forge participant consent.
