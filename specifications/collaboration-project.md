# Collaboration Project

An approved artifact may become a collaboration project.

Fields:

```text
title
problem
affected communities
source artifacts
cultural context
desired outcome
required skills
required languages
needed research
open questions
contributors
contribution needs
milestones
decisions
deliverables
impact evidence
status
```

Contribution types include research, translation, design, engineering, field testing, documentation, mentorship, equipment, introductions, data, local context, community trust, care work, funding, and other.

Money is one contribution type. v0.1 does not implement payment processing.
